# Preset Rhythm Patterns

This directory contains preset rhythm patterns that users can load into the Rhythm Trainer app. Patterns can be in two formats:

1. **JSON files** - Structured pattern data with metadata
2. **ABC files** - Standard ABC music notation

## JSON Pattern Structure

Each JSON pattern file contains:

- **name**: Display name of the pattern
- **description**: Brief explanation of the rhythmic concept
- **difficulty**: One of "beginner", "intermediate", or "advanced"
- **pattern**: The RhythmPattern object with bars, beatsPerBar, and notes array

```json
{
  "name": "Pattern Name",
  "description": "What this pattern teaches",
  "difficulty": "beginner|intermediate|advanced",
  "pattern": {
    "bars": 1,
    "beatsPerBar": 4,
    "notes": [
      { "duration": "q", "type": "note" }
    ]
  }
}
```

### Note Durations
- `w`: Whole note (4 beats)
- `h`: Half note (2 beats)
- `q`: Quarter note (1 beat)
- `8`: Eighth note (0.5 beats)
- `16`: Sixteenth note (0.25 beats)
- `q3`: Quarter triplet (2/3 beats)
- `83`: Eighth triplet (1/3 beats)

### Note Properties
- **duration**: One of the duration values above
- **type**: Either "note" or "rest"
- **tie**: (optional) Boolean - connects this note to the next
- **dotted**: (optional) Boolean - adds 50% to the duration

## ABC Pattern Format

ABC files use standard ABC music notation. The pattern metadata is specified using ABC headers:

```abc
X:1
T:Pattern Name
M:4/4
L:1/8
K:C
%%difficulty beginner
B/B/ B/B/ B/B/ B/B/ | B/B/ B/B/ B/B/ B/B/ |]
```

### ABC Headers
- `X:` - Reference number (always 1)
- `T:` - Title/name of the pattern
- `M:` - Time signature (e.g., 4/4, 3/4, 6/8)
- `L:` - Default note length (e.g., 1/4 = quarter, 1/8 = eighth)
- `K:` - Key signature (use C for no sharps/flats)
- `%%difficulty` - Custom field for difficulty level (beginner/intermediate/advanced)

### ABC Notation Basics
- `B` = Note (pitch doesn't matter for rhythm)
- `z` = Rest
- `/` = Half the default length (e.g., B/ = eighth if L:1/4)
- `2` = Double the length (e.g., B2 = half note if L:1/4)
- `|` = Bar line
- `|]` = Final bar line

## Pattern Index

The `index.json` file catalogs all available patterns for the UI to display. It's automatically generated by the `update-pattern-index.js` script, which scans both JSON and ABC files.

## Adding New Patterns

### Adding a JSON Pattern

1. Create a JSON file in this directory following the structure above
2. Run `npm run update-patterns` to regenerate the index
3. Ensure the pattern is rhythmically valid (total beats match bars × beatsPerBar)
4. Test the pattern in the app

### Adding an ABC Pattern

1. Create an ABC file with proper headers (including `%%difficulty`)
2. Use ABC notation for the rhythm (pitch doesn't matter, commonly use `B`)
3. Run `npm run update-patterns` to regenerate the index
4. Test the pattern in the app

The `update-patterns` script automatically:
- Scans for both `.json` and `.abc` files
- Extracts metadata (name, category) from each file
- Sorts patterns by difficulty and name
- Generates the `index.json` file

## Usage in the App

Users can access these patterns via the "🎵 Load Preset Patterns" button in the Pattern Designer. The UI groups patterns by difficulty level. Both JSON and ABC patterns appear in the same list and load seamlessly.

The patterns work in both development and production environments:
- **Development**: Loaded from `http://localhost:5173/patterns/`
- **Production**: Loaded from `https://bunsenstraat.github.io/rhythm-app/patterns/`

The PatternDesigner automatically detects the file type (.json or .abc) and uses the appropriate parser.
